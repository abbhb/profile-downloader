# v1.2.0：JSON 响应高亮、结构预览与复制

提供更接近 Network 的响应查看与一键复制体验。

- Response 区分 JSON 键、字符串、数字、布尔值和 `null`，格式化保留大整数、重复键及转义的原始写法。
- Preview 支持折叠查看对象和数组，每组按需加载 100 个子项，并可复制节点值。
- 一键复制原文或格式化 JSON。预览截断时可按需读取完整已记录响应，最多允许 20 × 1024 × 1024 个字符，不持久缓存完整正文。
- 对截断、无效 JSON 和二进制响应给出明确提示，剪贴板失败会反馈。响应通过安全 DOM 展示，不执行 HTML。
- 保持 22 px 单行请求列表和明确点击后重放 GET / POST 的流程，没有新增扩展权限。

Preview 和节点复制使用标准 JavaScript JSON 解析，可能改变大整数精度或重复键结果；不安全的解析数字禁止复制。精确内容以 Response 和原文复制为准，二进制复制明确标为 Base64 文本。

## 验证

43 项 Node 测试全部通过，源码、敏感材料、构建与发布包检查通过。18 组模拟浏览器检查覆盖高亮、无损格式化与复制、树的按需展开和分页、无效 / 二进制 / 截断响应、全文限制、剪贴板兼容处理、过期回调隔离，以及紧凑的明暗主题布局。

在 macOS 隔离 Chrome/133.0.6943.16、localhost 合成服务下，5 项真实扩展检查通过：HAR 响应读取、高亮与 Preview 可用，三类复制结果与系统剪贴板内容一致。该环境的 Clipboard API 被拒绝，兼容复制成功；现代 API 的成功路径由模拟检查覆盖。未新增权限，真实业务后端及服务端采样仍未验证。

下载并解压本次发布的 ZIP，重新加载已解压扩展并重新打开 DevTools。复制读取已记录的响应数据，不重放接口；后端分析报告的接入要求保持一致。详见[使用说明](https://github.com/abbhb/profile-downloader/blob/v1.2.0/docs/usage.md)和[验证范围](https://github.com/abbhb/profile-downloader/blob/v1.2.0/docs/testing.md)。

# Profile Downloader v1.2.0

JSON response inspection / 更接近 Network 的响应查看与一键复制。

- Syntax-highlight JSON keys, strings, numbers, booleans and `null` in Response, with token-preserving formatting for large integers, duplicate keys and escapes.
- Inspect objects and arrays in a collapsible Preview tree, with lazy groups of 100 children and node-value copying.
- Copy the original response or formatted JSON with one click. Truncated previews can read complete recorded text on demand, up to 20 × 1024 × 1024 characters, without persistently caching the full body.
- Clearly identify truncated, invalid JSON and binary responses; clipboard failures are reported. Response content is rendered with safe DOM and is never executed as HTML.
- Preserve 22 px single-line request rows and the existing explicit GET / POST profiling workflow. No new extension permissions.

Response 支持 JSON 语法高亮；Preview 可折叠展开对象与数组，分组按需加载，并复制节点值。可一键复制完整原文或格式化 JSON，预览与复制长度限制分别控制，失败时明确提示。

Preview and node copying use standard JavaScript JSON parsing, which may change large-number precision or duplicate-key results; unsafe parsed numbers cannot be copied. Use Response / original copying for exact data. Binary copying is explicitly Base64 text.

## Validation / 验证

43 / 43 Node tests passed, along with source, security, build and release-package checks. Eighteen mocked-browser groups covered highlighting, lossless formatting / copying, lazy trees and pagination, invalid / binary / truncated responses, full-text limits, clipboard fallbacks, stale callbacks and compact light / dark layouts.

Five real-extension checks passed in isolated Chrome/133.0.6943.16 on macOS against a localhost synthetic service: HAR response reading, highlighting / Preview and three copy operations matched the system clipboard. The modern Clipboard API was denied in that environment and legacy copying succeeded; modern-API success was covered by mocks. No new permissions were added. Real business backends and server-side sampling remain unverified.

Download and extract this Release's ZIP, reload the unpacked extension and reopen DevTools. Copying reads recorded response data; it does not replay the endpoint. Backend profiling requirements remain unchanged.

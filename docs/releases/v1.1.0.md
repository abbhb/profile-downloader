# v1.1.0：首次开源发布

Profile Downloader 首次公开发布，采用 MIT 许可证。

## 本版变化

- 提供 Network 风格请求表格，展示 Name、Method、Status、Type、Size、Time 和 Waterfall，支持排序、搜索、方法和类型筛选、录制及保留日志。
- 提供 Headers、Payload、Response、Timing 详情，可查看完整接口 URL，并按需读取响应预览。
- 在 Profile 面板内右键请求，可选中接口并打开分析操作；只有点击重放按钮才会发送请求。
- 为支持的 GET / POST 请求添加 `profile=1` 后重放，下载成功返回的 Pyinstrument HTML 报告。
- 提供本地合成测试、源码与敏感材料检查、可复现构建的扩展 ZIP 及 SHA-256 校验文件。
- 补充后端兼容性、隐私和发布流程文档。

## 安装

下载本次发布的 ZIP 与校验文件，校验后解压。在 `chrome://extensions` 或 `edge://extensions` 启用“开发者模式”，点击“加载已解压的扩展程序”，选择含 `manifest.json` 的目录。重新打开 DevTools，选择 **Profile**。

## 适用范围与限制

面向桌面 Chrome 和基于 Chromium 的 Edge，使用 Manifest V3、原生 JavaScript ES modules、HTML 和 CSS。Node.js 22+ 仅用于开发检查与打包。

后端必须已支持在收到 `profile=1` 时返回 Pyinstrument HTML。Django 可使用 Pyinstrument 中间件，其他应用需要兼容集成；`BKAPP_OPEN_PYINSTRUMENT` 属于特定应用配置。

原生 Network 请求行右键菜单没有公开扩展入口。本版通过独立 Profile 面板提供 Network 风格列表和自己的右键菜单。

POST 会再次执行业务操作。仅支持完整 UTF-8 文本请求体；multipart、文件、二进制、非 UTF-8 和缺失的请求体会被拒绝。CORS、CSP、登录和 CSRF 校验仍然生效，取消不能回滚服务器操作。

## 验证

在本地 Node.js v24.14.1 下，29 项合成测试全部通过，源码、Manifest、版本检查与静态敏感材料检查通过。

GitHub CI 的 Ubuntu / Node.js 22、Ubuntu / Node.js 24、macOS / Node.js 22 三个矩阵通过。

使用模拟 DevTools API 的浏览器检查覆盖右键选择、GET / POST 重放参数、详情、筛选、数值排序、键盘焦点、取消、导航与清空、录制、300 条上限、主题和窄面板。测试服务返回合成渲染器 HTML，不代表真实 Pyinstrument 后端采样验证。详见[验证范围](https://github.com/abbhb/profile-downloader/blob/v1.1.0/docs/testing.md)。

在 macOS 的隔离 Chrome/133.0.6943.16 中，10 项真实扩展检查通过，覆盖真实 DevTools GET / POST 捕获、右键不自动发送、明确点击后各发送一次、查询参数、模拟登录态、CSRF、POST 请求体保留，以及通过真实扩展 API 链路保存两份 HTML。测试使用 CDP 定向下载，未验证 `saveAs` 原生文件选择器。localhost 测试服务返回合成渲染器 HTML，真实 Pyinstrument 采样和业务后端集成仍未验证。

使用方法、数据处理和验证说明见仓库 [README](https://github.com/abbhb/profile-downloader#readme) 与[文档](https://github.com/abbhb/profile-downloader/tree/v1.1.0/docs)。

# Profile Downloader v1.1.1

Fix request-list density / 修复请求列表占用过高，单屏可查看更多接口。

- Default to 22 px single-line rows; show the endpoint name and expose its full URL on hover and in Headers.
- Tighten column widths and adapt narrow lists by hiding Waterfall / Type when needed. Full request details remain available.

默认请求行改为 22 px 单行，完整 URL 可悬停或进入 Headers 查看；窄列表按需调整可见列。

在 633 × 870 像素面板、52 条合成请求下，行高从 38 px 降到 22 px，单屏完整请求行从 19 条增加到 34 条；表格宽度由 700 px 适配为 633 px，无横向溢出。

Validation: 29 / 29 Node tests and source / security / build / release checks passed. Browser UI regression with mocked DevTools APIs passed at widths 1280, 633, 560, 441, 440 and 375 px, including full-URL access, context-menu behavior, POST replay / download, keyboard selection and light / dark themes. This patch's UI check does not claim new real-DevTools or backend sampling validation.

Download and extract this Release's ZIP, reload the unpacked extension, then reopen DevTools. Backend requirements and the explicit GET / POST replay flow are unchanged.
